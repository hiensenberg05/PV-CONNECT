# PV Connect Dashboard

Next.js dashboard for PV Connect pharmacovigilance system.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Backend Connection

Make sure the backend is running on `http://localhost:8000` for the dashboard to connect properly.
